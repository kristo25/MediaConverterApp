Safer defaults for real files.

The app is designed to avoid accidental data loss. Originals are preserved by default, and delete-original mode only runs after a successful conversion and output validation.

What the app stores locally

  • Settings and recent folders under LocalAppData.
  • Conversion logs under LocalAppData.
  • Optional ffmpeg files if you use the built-in convenience installer.
  • No converted media files are stored in app data.

Download the Windows executable.

The release includes a self-contained Windows exe. ffmpeg can be selected manually, discovered from PATH, or downloaded through the app's convenience installer.

No setup is required. To uninstall, delete the exe. Use Settings > Clear app data first if you want to remove settings, logs, and app-downloaded ffmpeg.
