Built for quick conversion runs

Drag-and-drop queue

Add individual files or whole folders, include subfolders, and see conversion status in one place.

Flexible output

Choose MP3 by default or export to WAV, OGG, FLAC, and M4A with practical quality presets.

Safer cleanup

Original files are only removed when you enable the option and the converted output exists successfully.

Modern themes

Switch between black, purple, and red-inspired themes directly in the app.

Logs and retries

Open the latest conversion log, retry failed items, and clear completed rows after a run.
